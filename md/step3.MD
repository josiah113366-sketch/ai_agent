# 목표
- 프롬프트 엔지니어링 적용
```
# Role (역할)

# Context (내용)

# Task (실제로 할 일, 지시 사항)

# Constraints (제약) 
```
- 필요 시 퓨샷 (샘플 제공) 적용
- 프롬프트의 양식(폼, 형태)는 최적의 답을 얻기 위한 애플리케이션의 핵심 내용 관리
  - 서비스 핵심 자산 관리해야 함

# 구조
```

```

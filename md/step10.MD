# 목표
- 문단 단위 청킹, 시맨틱 청킹
- 메타데이터 필터링 
- 벡터 + 키워드 하이브리드 검색 (추론 시 비율로 활용)

# 시맨틱 청킹
- 말뭉치 -> 분절 (문장/문단 단위 (단순하게 구성 : . ! ? ...)) -> 각 단위별 임베딩 -> 인접에 대한 유사도 계산 (앞뒤 벡터간 유사도 계산) -> 유사도가 특정 임계값보다 낮아지는 지점 체크 + 최소 토큰(문자)수 -> 청킹
- 유사도가 높은 문장/문단간 청킹 진행
- 임계값의 최적화는 다른 문제 -> 차후 추론 등 과정을 통해 평가 진행 (최적 청킹에 대한 평가)
- 임계값은 임시 설정
  - 변수 : 임베딩 모델, 문서(말뭉치 원소스)의 구성과 특성, 임계값, 사용(추론 행위) -> 평가

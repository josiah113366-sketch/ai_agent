## 📄 상품 하자 환불 정책 (문서: CS-REFUND-2026)

고객센터(CS) 정책 문서를 기준으로 상품 하자 관련 환불 규정은 다음과 같습니다.

1. **신청 가능 기간**
   - 상품의 제조상 하자 또는 기능상 문제가 확인된 경우, **상품 수령 후 30일 이내** 교환 또는 환불 신청 가능.

2. **비용 부담**
   - 고객에게 귀책사유가 없는 것으로 판단되면, **회수 배송비 및 교환 상품 재배송비는 회사가 부담**.

3. **검증 절차**
   - 고객센터는 하자 확인을 위해 **사진, 동영상, 제품 상태 확인 자료**를 요청할 수 있음.
   - 환불은 반품 상품이 물류센터에 도착 후 **검수(사용 여부, 구성품 누락, 훼손 여부, 반품 사유 확인)**를 거쳐 진행됨.

4. **환불 방식**
   - 정상 반품 확인 시 **원결제 수단 기준으로 환불**. 카드사/PG사 처리 일정에 따라 실제 환불 완료 시점은 차이가 있을 수 있음.

5. **예외 사항**
   - 반품 상품에 사은품/증정품이 포함된 경우 함께 반환해야 하며, 미반환·사용 시 해당 금액이 환불금에서 차감될 수 있음.
   - 세트 상품은 특별 안내가 없는 한 **전체 구성 기준**으로 반품 여부 판단.
   - 고객 과실로 인한 훼손이나 사용 흔적이 명확한 경우, 가치가 현저히 감소한 경우 반품이 제한될 수 있음 (단, 이는 '하자'가 아닌 '단순 변심/고객 과실' 케이스에 적용되는 제한 조항).

필요하시면 환불 데이터 조회 도구가 복구된 후 다시 요청해 상세 현황을 안내드리겠습니다.
